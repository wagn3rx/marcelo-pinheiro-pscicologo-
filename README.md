# 🧠 Landing Page: Marcelo Psi

[![Acessar Projeto Online](https://img.shields.io/badge/Acessar-Site_Online-007ACC?style=for-the-badge&logo=vercel&logoColor=white)](https://marcelo-pinheiro-pscicologo-5162.vercel.app/)

Este é um projeto de landing page desenvolvido para o consultório de psicologia de Marcelo Pinheiro. O objetivo principal é fornecer um canal de contato direto, transmitindo segurança e profissionalismo para pacientes em potencial.

### 🎯 Objetivo do Projeto
Criar uma interface focada em conversão, que apresente a especialidade do profissional, sua abordagem terapêutica e facilite o agendamento de consultas e o acesso às informações de contato.

### 🛠 Tecnologias Utilizadas
*   **Front-end:** HTML5, CSS3, JavaScript.
*   **Design:** Focado em uma paleta de cores neutras e calmantes para transmitir bem-estar.
*   **Responsividade:** Layout totalmente adaptável para dispositivos móveis. <br> ![](https://img.shields.io/badge/Layout-Mobile_First-007ACC?style=flat&logo=smartphone&logoColor=white)

### ✨ Funcionalidades Principais
*   **Seção de Apresentação:** Breve resumo sobre a abordagem clínica e experiência.
*   **Agendamento Rápido:** Botão de CTA direto para contato via WhatsApp.
*   **Localização:** Botão integrado com **Google Maps** para facilitar o acesso ao consultório.
*   **Redes Sociais:** Ícone de acesso rápido ao **Instagram profissional**.
*   **Seção de Dúvidas (FAQ):** Respostas rápidas sobre o funcionamento do atendimento.

### 🚀 Como rodar o projeto localmente
Para visualizar o projeto em sua máquina:

1. Clone este repositório:
   `git clone [link-do-repositorio]`
2. Abra o arquivo `index.html` diretamente no seu navegador.
